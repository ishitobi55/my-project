# メルカリ 高評価件数出品者 抽出スクリプト

キーワード検索に出てくる出品者のうち、評価件数が指定数（既定 10,000 件）以上の人を CSV に書き出します。

## 準備（初回のみ）

Python 3.9 以上が必要です。

```
pip install -r requirements.txt
playwright install chromium
```

## 実行

```
python mercari_sellers.py "トレカ"
```

主なオプション:

| オプション | 意味 | 既定 |
|---|---|---|
| `--pages N` | 検索結果を何ページ分見るか | 3 |
| `--min-ratings N` | 評価件数の下限 | 10000 |
| `--out FILE` | 出力 CSV | sellers.csv |
| `--min-wait` / `--max-wait` | アクセス間隔（秒） | 3 / 6 |
| `--headless` | ブラウザ画面を出さない | オフ |

結果は `sellers.csv`（Excel でそのまま開けます）に、評価件数の多い順で出ます。
確認済みの出品者は `profile_cache.json` に保存されるので、途中で止めても再実行すれば続きから進みます。

## 注意

- メルカリShops の出品者は対象外です（通常のプロフィールページがないため）。
- 大量アクセスは利用規約違反やアクセス制限の原因になります。ページ数は少なめ、待機時間は長めにしてください。
- サイトの仕様変更で評価件数が読めなくなることがあります。その場合は終了時に件数が表示されます。
